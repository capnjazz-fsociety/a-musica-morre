Identidade Visual AMV

Base: Este arquivo é desenvolvido a partir do chat "Identidade Visual AMV" + este projeto de Comunicação.

O que precisa ser definido

  • Paleta de cores — cores primárias e secundárias, usos por canal
  • Tipografia — fontes para títulos, corpo, destaques
  • Linguagem fotográfica — estilo de fotos para Instagram, site, newsletter (tom, filtros, enquadramento)
  • Tom de voz — como a AMV "fala" por escrito (informal? editorial? técnico? poético?)
  • Elementos gráficos — ícones, texturas, molduras para stories/posts
  • Templates — modelos base para carrossel, story, post, newsletter

Questionamentos

  • A identidade visual atual da AMV (logo, cores do site) serve como ponto de partida ou precisa ser repensada?
  • O tom de voz muda entre canais? (Ex: Instagram mais informal, Newsletter mais editorial)
  • Existe referência visual de outras agências/projetos que você admira?
  • Os artistas AMV têm identidades visuais próprias fortes? A AMV precisa conviver com elas sem conflitar
  • O Na Cena deveria ter identidade visual própria (sub-marca) ou seguir a AMV?

Entregáveis esperados

  • Guia de identidade visual (paleta, tipografia, tom de voz)
  • Templates Instagram (carrossel, reels cover, story)
  • Template Newsletter
  • Diretrizes de fotografia/vídeo
